# AttendX-Test-Scripts

## Project Description
This repository contains basic automation test scripts
for the AttendX student attendance application.

## Test Scripts
1. test_login.py
   - Checks that login input fields are not empty.

2. test_attendance.py
   - Checks student ID and attendance status.

## Requirements
- Python 3

## Execution
Run the scripts using:

python test_login.py
python test_attendance.py

## Version Control
Git is used to track changes, and GitHub is used
to store and share the test scripts.
